# 开发阶段计划 — 宅家激励 App

> 版本：v1.0 | 日期：2026-08-03 | 总阶段：9 个（阶段 0-8）

---

## 执行原则

1. **严格按顺序**：每阶段独立验证后再进入下一阶段
2. **每阶段可交付**：任何阶段完成后项目都处于可用状态
3. **小步提交**：每个步骤完成即视为里程碑
4. **每日日志**：每次开发会话后更新 `devlogs/YYYY-MM-DD.md`

## 阶段 2：数据层（让数据流动）

**目标**：实现 localStorage 读写，应用启动时正确初始化或恢复数据。

| 步骤 | 内容 | 产出物 |
|------|------|--------|
| 2.1 | 实现存储核心函数 | `js/storage.js`（get/save/init/reset） |
| 2.2 | 首次使用自动初始化默认数据 | 初始积分 500，4 种宠物可选 |
| 2.3 | 每日免费刷新次数自动重置 | 检查日期，跨天重置为 3 |
| 2.4 | 心情值每日衰减计算 | 每天未完成任务心情 -15 |

**验证标准**：控制台调用函数确认数据正确读写，手动改日期测试每日重置。

## 阶段 3：任务系统（核心功能）

**目标**：任务随机抽取、刷新、完成全流程跑通。

| 步骤 | 内容 | 产出物 |
|------|------|--------|
| 3.1 | 预设任务库（20+ 条，三档难度） | `js/tasks.js` |
| 3.2 | 随机抽取（不连续重复） | `getRandomTask()` |
| 3.3 | 刷新逻辑（免费 3 次→积分 20/次） | `refreshTask()` |
| 3.4 | 完成任务（积分+历史+触发成长） | `completeTask()` |
| 3.5 | 首页卡片与数据联动渲染 | 首页实时显示当前任务 |

**验证标准**：完整走通"查看任务 → 刷新任务 → 完成任务 → 积分增加"流程。
