# 产品需求文档 — 宅家激励 App

> 版本：v1.0 | 日期：2026-08-03 | 状态：已确认

---

## 1. 产品概述

### 1.1 产品名称
**暂定**：宅家激励（后续可改名）

### 1.2 一句话描述
通过"户外任务 → 积分奖励 → 宠物养成"的正向循环，帮助宅家人士找回外出动力的温馨陪伴型 Android PWA 应用。

### 1.3 目标用户
- **主要用户**：长期宅在家中、缺乏外出动力的人
- **核心痛点**：日益增长的孤独感、缺乏社交和外出的动力
- **使用场景**：每天打开 App，获取一个随机户外任务，完成后获得积分喂养宠物

### 1.4 产品定位
- **风格**：简洁、温馨、蓝色主色调
- **氛围**：像一个小伙伴在陪伴和鼓励你，不是冷冰冰的任务工具
- **平台**：Android 手机（PWA 方式安装）

---

## 2. 核心机制

```
┌──────────┐    ┌──────────┐    ┌──────────┐    ┌──────────┐
│ 随机获取  │ → │  出门完成  │ → │  回来确认  │ → │  获得积分  │
│ 户外任务  │    │  户外任务  │    │  （点按钮） │    │          │
└──────────┘    └──────────┘    └──────────┘    └─────┬────┘
                                                      │
                                          ┌───────────┘
                                          ▼
                                    ┌──────────┐
                                    │ 积分喂养/ │ ← 长时间不做任务
                                    │ 装扮宠物  │ → 宠物心情变差 😿
                                    └──────────┘
```

## 3. 功能需求

### 3.1 页面结构（底部 4 个 Tab）

| Tab | 图标 | 名称 | 功能概要 |
|-----|------|------|---------|
| 1 | 🏠 | 首页 | 展示今日随机任务，可刷新和完成 |
| 2 | 🐾 | 宠物 | 宠物展示、互动、成长、心情 |
| 3 | 👤 | 用户 | 积分、任务历史、成就徽章 |
| 4 | ⚙️ | 设置 | 自定义任务、提醒、更换宠物 |

### 3.2 首页 — 任务系统

#### 3.2.1 任务展示
- 打开 App 即看到今日随机任务卡片
- 卡片显示：难度标签、任务标题、奖励积分预览
- 任务来源：预设任务库 + 用户自定义任务

#### 3.2.2 任务规则
| 规则 | 详情 |
|------|------|
| 任务类型 | **纯户外任务**（散步、去书店、逛公园、找朋友等） |
| 难度分级 | 简单（30 积分）/ 中等（50 积分）/ 困难（80 积分） |
| 完成方式 | 用户自行点"完成"按钮（信任机制） |
| 每日免费刷新 | **3 次**，超出后每次消耗 20 积分 |
| 刷新重置 | 每日 0 点自动重置免费次数 |

#### 3.2.3 预设任务库（示例，实现时扩充至 20+ 条）

**简单（30 积分）**：
- 下楼散步 10 分钟
- 去楼下取快递
- 出门倒垃圾
- 去阳台晒 5 分钟太阳
- 去便利店买瓶水
- 在家门口站 5 分钟呼吸新鲜空气

**中等（50 积分）**：
- 去附近的公园坐坐
- 逛书店 20 分钟
- 去咖啡馆喝一杯
- 去超市买点东西
- 去操场走 5 圈
- 骑共享单车兜风 15 分钟

**困难（80 积分）**：
- 去爬山
- 去博物馆参观
- 约朋友一起吃饭
- 骑行 5 公里
- 参加一个社区活动
- 去电影院看一场电影

#### 3.2.4 自定义任务
- 用户可在设置页添加自己的户外任务
- 自定义任务需选择难度（决定积分）
- 可删除自己添加的任务
- 预设任务不可删除

### 3.3 宠物页 — 宠物系统

#### 3.3.1 宠物类型
- 🐱 小猫
- 🐶 小狗
- 🐰 小兔
- 🐤 小鸟

首次使用时可选择，后续可在设置页更换（保留成长数据）。

#### 3.3.2 宠物属性
| 属性 | 范围 | 说明 |
|------|------|------|
| 名字 | 用户自定义 | 首次选择宠物时起名 |
| 等级 | 1-10 级 | 成长值满 100 升级 |
| 成长值 | 0-100 | 完成任务获得（简单+10/中等+20/困难+35） |
| 心情值 | 0-100 | 每天未完成任务 -15；低于 40 宠物不开心；归零生病 |

#### 3.3.3 互动功能
| 互动 | 消耗 | 效果 |
|------|------|------|
| 🍖 喂食 | 20 积分 | 心情 +20 |
| 🎾 玩耍 | 10 积分 | 心情 +15 |

每日互动次数不限，只要有足够积分。

#### 3.3.4 鼓励话语
宠物会随机显示预设的鼓励语句，例如：
- "今天天气一定很好，出去走走吧！"
- "我想你了，快完成任务回来看看我~"
- "你是最棒的！今天也要加油哦！"

#### 3.3.5 成长表现
| 等级 | 阶段 | 外观变化 |
|------|------|---------|
| 1-3 | 幼崽期 | 体型较小 |
| 4-6 | 成长期 | 体型中等 |
| 7-9 | 成熟期 | 体型较大 |
| 10 | 完全体 | 特殊外观（加星星/光环） |

### 3.4 用户页 — 个人中心

#### 3.4.1 积分展示
- 顶部大卡片显示当前积分余额
- 积分通过完成任务获得

#### 3.4.2 成就徽章
| 成就 | 条件 |
|------|------|
| 🌱 初次出门 | 完成第 1 个任务 |
| 🚶 小小行者 | 累计完成 5 个任务 |
| 🏃 户外达人 | 累计完成 20 个任务 |
| 🎯 百次挑战 | 累计完成 100 个任务 |
| ⭐ 困难征服者 | 完成 10 个困难任务 |
| 💪 坚持一周 | 连续 7 天完成任务 |
| 🔥 月度之星 | 连续 30 天完成任务 |

#### 3.4.3 任务历史
- 按时间倒序展示已完成任务
- 每条记录显示：日期、任务名称、获得积分

### 3.5 设置页

| 功能 | 说明 |
|------|------|
| 自定义任务管理 | 添加新任务（标题+难度）、查看/删除已有自定义任务 |
| 每日提醒 | 开关 + 提醒时间设置 |
| 更换宠物 | 4 种宠物切换（保留等级和成长值） |
| 关于 | 版本号信息 |

## 4. 非功能需求

### 4.1 无需注册登录
- 打开即用，所有数据存储在手机本地（localStorage）

### 4.2 离线可用
- 通过 PWA Service Worker 实现离线缓存
- 首次加载后可离线使用

### 4.3 可安装
- 支持添加到 Android 手机主屏幕
- 通过 Chrome 浏览器打开 → 添加到主屏幕

### 4.4 性能
- 纯 HTML/CSS/JS，无第三方框架依赖
- 首次加载 < 2 秒
- 页面切换即时响应

### 4.5 设计风格
- **主色调**：蓝色系（温暖蓝，不冷淡）
- **风格**：圆角卡片、柔和阴影、大字体、emoji 图标
- **氛围**：温馨、可爱、鼓励性

## 5. 不做的功能（明确排除）

- ❌ 宠物 AI 对话（去掉）
- ❌ 用户注册/登录系统
- ❌ 云端数据同步
- ❌ 社交功能（好友、分享）
- ❌ 任务验证（拍照/GPS）
- ❌ 推送通知（PWA 限制，但可做本地提醒）
